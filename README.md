# Dream Land Properties

A modern Flutter web app for showcasing Dream Land Properties company information,
services, and project status in a polished single-page experience.

## Included sections

- Company introduction, mission, and vision
- Upcoming, completed, and pending project showcases
- Construction services and buyer-focused website features
- Buyer journey, trust points, and contact call-to-actions

## Run locally

```bash
flutter run -d chrome
```
